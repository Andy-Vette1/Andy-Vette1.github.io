## Week 3 Intro to RL; Bellman equations, policy and value Iteration    

### 整体脉络

本节课核心问题：**在已知模型（P 和 R）的情况下，如何找到最优策略？**

逻辑链：MDP 定义问题 → Bellman 方程描述价值 → Policy / Value Iteration 求解最优策略

---

### 1. MDP 是什么？

MDP（Markov Decision Process，马尔可夫决策过程）是 RL 的基础建模框架，由五元组 $(S, A, P, R, \gamma)$ 定义：

- $S$：有限状态集合
- $A$：有限动作集合
- $P^a_{s,s'} = P[S_{t+1}=s' \mid S_t=s, A_t=a]$：转移概率矩阵
- $R^a_s = \mathbb{E}[R_{t+1} \mid S_t=s, A_t=a]$：期望即时奖励函数（依赖状态和动作，不是集合）
- $\gamma \in [0,1]$：折扣因子

**关于 $\gamma$ 的直觉：**

- $\gamma$ 接近 0：agent 只看重当前的即时奖励，短视
- $\gamma$ 接近 1：agent 重视长期回报，有远见

**策略**（Policy）是从状态到动作的映射：

- 确定性策略：$a = \pi(s)$
- 随机策略：$\pi(a \mid s) = P[\text{Action}=a \mid \text{State}=s]$

---

### 2. 两种价值函数

**状态价值函数** $v_\pi(s)$：从状态 $s$ 出发，按策略 $\pi$ 行动，期望能获得的总折扣回报。

$$v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$$

**状态-动作价值函数** $q_\pi(s, a)$：在状态 $s$ **先执行动作 $a$** ，之后再按策略 $\pi$ 行动，期望能获得的总折扣回报。

$$q_\pi(s, a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a]$$

**关键区别**：$q_\pi(s,a)$ 比 $v_\pi(s)$ 多指定了一个动作 $a$。

**两者的关系**：$v_\pi(s)$ 是 $q_\pi(s,a)$ 对所有动作按策略概率的加权平均：

$$v_\pi(s) = \sum_a \pi(a \mid s) \cdot q_\pi(s, a)$$

---

### 3. Bellman 期望方程

Bellman 方程把价值函数递归分解为**即时奖励**和**折扣后的未来价值**两部分。

**对状态价值函数：**

$$v_\pi(s) = \mathbb{E}\left[R_{t+1} + \gamma v_\pi(S_{t+1}) \mid S_t = s\right]$$

展开期望：

$$v_\pi(s) = \sum_a \pi(a \mid s) \left[ R^a_s + \gamma \sum_{s'} P^a_{s,s'} v_\pi(s') \right]$$

逐项含义：

- $R^a_s$：执行动作 $a$ 后立刻获得的即时奖励
- $v_\pi(S_{t+1})$：到达下一状态后，继续按 $\pi$ 行动的总价值
- $\gamma$：对未来价值打折扣
- $\mathbb{E}[\cdot]$：因为转移是随机的，所以取期望

**对状态-动作价值函数：**

$$q_\pi(s, a) = \mathbb{E}\left[R_{t+1} + \gamma q_\pi(S_{t+1}, A_{t+1}) \mid S_t=s, A_t=a\right]$$

**闭式解（矩阵形式）：**

$$v_\pi = R^\pi + \gamma P^\pi v_\pi \implies v_\pi = (I - \gamma P^\pi)^{-1} R^\pi$$

实践中状态空间过大，矩阵求逆不可行，需用迭代方法。

---

### 4. 最优价值函数与 Bellman 最优方程

"解 MDP"等价于找到最优策略，即找使价值函数最大的策略：

$$v^*(s) = \max_\pi v_\pi(s), \quad q^*(s,a) = \max_\pi q_\pi(s,a)$$

**关键结论** ：最优策略就是对 $q^*$ 贪心：

$$
\pi^*(a \mid s) =
\begin{cases}
1, & \text{if } a = \arg\max_{a'} q^*(s, a') \\\\
0, & \text{otherwise}
\end{cases}
$$

且最优策略**一定存在确定性的形式**。

**Bellman 最优方程：**

$$v^*(s) = \max_a \left[ R^a_s + \gamma \sum_{s'} P^a_{s,s'} v^*(s') \right]$$

$$q^*(s,a) = R^a_s + \gamma \sum_{s'} P^a_{s,s'} \max_{a'} q^*(s', a')$$

**与期望方程的关键区别**：

| | Bellman 期望方程 | Bellman 最优方程 |
|:---:|:---:|:---:|
| 对动作的处理 | $\sum_a \pi(a\|s)$（按策略加权平均）| $\max_a$（直接取最大值）|
| 用途 | 评估某个策略的好坏 | 寻找最优策略 |
| 是否线性 | 线性，有闭式解 | 非线性，无闭式解，必须迭代 |

---

### 5. Policy Iteration（策略迭代）

**思路**：交替做两件事，直到策略不再变化。

1. **Policy Evaluation**：固定当前策略 $\pi$，反复用 Bellman 期望方程迭代，直到 $v_\pi$ 收敛
2. **Policy Improvement**：根据 $v_\pi$ 做 greedy 改进，得到新策略 $\pi' = \text{greedy}(v_\pi)$
3. 用新策略 $\pi'$ 回到第一步，循环直到策略收敛到 $\pi^*$

Policy Improvement 保证每次新策略一定不差于旧策略，因此保证收敛到 $\pi^*$。

---

### 6. Value Iteration（价值迭代）

**思路**：把 Policy Iteration 中的 Evaluation 步骤压缩为只做一步，直接用 Bellman 最优方程迭代价值函数。

$$v_{k+1}(s) = \max_a \left[ R^a_s + \gamma \sum_{s'} P^a_{s,s'} v_k(s') \right]$$

收敛后从 $v^*$ 推出最优策略，**过程中没有显式的策略**。

---

### 7. Policy Iteration vs Value Iteration

| | Policy Iteration | Value Iteration |
|:---:|:---:|:---:|
| 起点 | 随机策略 | 随机价值函数 |
| 优化对象 | 策略 $\pi$ | 价值函数 $v$ |
| 每轮工作量 | 大（需完整 Evaluation）| 小（一步更新）|
| 收敛轮数 | 少 | 多 |
| 算法复杂度 | 较复杂 | 较简单 |
| 是否需要模型 | 需要 $P$ 和 $R$ | 需要 $P$ 和 $R$ |

两者都是 **model-based** 方法，都需要已知转移矩阵 $P$ 和奖励函数 $R$。这是它们共同的局限性，也是引出 model-free 方法（MC、TD、SARSA、Q-Learning）的动机。

---

### 8. Take-home lessons

- MDP 是 RL 最基础的建模框架，MDP = MRP + 动作
- 状态价值函数描述状态有多好，状态-动作价值函数描述在某状态做某动作有多好
- 找最优策略等价于找使价值函数最大的策略
- Bellman 期望方程是线性的，有闭式解；Bellman 最优方程是非线性的，必须迭代求解
- Policy Iteration 和 Value Iteration 都需要完整模型（P, R），属于 model-based 方法
- 最优策略一定可以写成确定性的贪心策略

## Week 4 SARSA, Q-learning

### 整体脉络

本节课核心问题：**在不知道模型（P 和 R）的情况下，如何找到最优策略？**

分两步推进：

- **Step 1**：从 model-based prediction → model-free prediction（用采样替代转移矩阵）
- **Step 2**：从 model-free prediction → model-free control（用 Q 函数替代 V 函数）

---

### 1. 为什么需要无模型方法？

Model-based 方法的策略更新需要已知奖励函数 $R$ 和转移概率 $P$：

$$v'(s) \to \max_{a \in A} \left[ R^a_s + \gamma \sum_{s' \in S} P^a_{s,s'} v_{s'} \right]$$

现实中 $R$ 和 $P$ 往往未知。

**解决方案**：用**采样**替代求期望，不再需要 $P$。

---

### 2. MC vs TD（预测层面）

两者都是无模型预测，区别在于用什么来作为更新目标。

|                      |                    Monte-Carlo                    |                                   TD(0)                                   |
| :------------------: | :-----------------------------------------------: | :-----------------------------------------------------------------------: |
|       更新目标       |         完整回报 $G_t$（等 episode 结束）         |                  单步估计 $R_{t+1} + \gamma V(S_{t+1})$                   |
|       更新公式       | $V(S_t) \leftarrow V(S_t) + \alpha(G_t - V(S_t))$ | $V(S_t) \leftarrow V(S_t) + \alpha(R_{t+1} + \gamma V(S_{t+1}) - V(S_t))$ |
|     偏差 / 方差      |                  零偏差，高方差                   |                              有偏差，低方差                               |
| 是否需要完整 episode |                       必须                        |                                  不需要                                   |
|       适用环境       |               仅 episodic（有终止）               |                          episodic 或 continuing                           |

TD 括号内的量 $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$ 称为 **TD error**，是整个 TD 系列算法的核心。

---

### 3. 从预测到控制：为什么用 Q 而不用 V？

基于 $V(s)$ 的 greedy 策略改进仍然需要模型：

$$\pi'(s) = \arg\max_{a \in A} \left[ R^a_s + P^a_{s,s'} V(s') \right] \quad \text{（仍需 } R \text{ 和 } P \text{）}$$

改用 **$Q(s,a)$** 可以完全绕开模型：

$$\pi'(s) = \arg\max_{a \in A} Q(s, a) \quad \text{（model-free）}$$

因此控制问题转化为：**如何学到 Q 函数？**

---

### 4. SARSA（On-Policy TD Control）

SARSA 是 on-policy 的 TD 控制算法，名称来自其使用的五元组 $(S, A, R, S', A')$。

**更新公式：**

$$Q(S,A) \leftarrow Q(S,A) + \alpha \left[ R + \gamma Q(S', A') - Q(S,A) \right]$$

**算法流程：**

1. 初始化 $Q$ 表，令 $Q(\text{terminal}, \cdot) = 0$
2. 初始化状态 $S$，用 $\varepsilon$-greedy 从 $Q$ 选择动作 $A$
3. 执行 $A$，观察 $R$、$S'$
4. 从 $S'$ 用 $\varepsilon$-greedy 选择 $A'$
5. 用上式更新 $Q(S, A)$
6. $S \leftarrow S'$，$A \leftarrow A'$，回到步骤 3，直到 $S$ 为终止态

关键点：$A'$ 是按**当前策略**（$\varepsilon$-greedy）在 $S'$ 上选出的，因此是 on-policy。

**收敛条件（需同时满足）：**

- GLIE 策略序列：既保证无限探索，又最终收敛为贪心策略
- Robbins-Monro 步长条件：$\sum_t \alpha_t = \infty$，$\sum_t \alpha_t^2 < \infty$

---

### 5. Q-Learning（Off-Policy TD Control）

Q-Learning 是 off-policy 的 TD 控制算法。

**更新公式：**

$$Q(S,A) \leftarrow Q(S,A) + \alpha \left[ R + \gamma \max_{a'} Q(S', a') - Q(S,A) \right]$$

**与 SARSA 的核心区别**：更新时 $S'$ 处不使用实际执行的动作，而是直接取最大值。

**算法流程：**

1. 初始化 $Q$ 表，令 $Q(\text{terminal}, \cdot) = 0$
2. 初始化状态 $S$
3. 用 $\varepsilon$-greedy 选择动作 $A$，执行后观察 $R$、$S'$
4. 用上式更新 $Q(S, A)$
5. $S \leftarrow S'$，回到步骤 3，直到 $S$ 为终止态

- **行为策略**（实际执行）：$\varepsilon$-greedy，保证探索
- **目标策略**（更新用）：greedy（直接取 $\max$）

两个策略不同，因此是 off-policy。Q-Learning 收敛到最优 $q^*$。

---

### 6. SARSA vs Q-Learning 对比

|            |                   SARSA                   |            Q-Learning            |
| :--------: | :---------------------------------------: | :------------------------------: |
|  策略类型  |                 On-policy                 |            Off-policy            |
|  更新目标  | $R + \gamma Q(S', A')$，$A'$ 来自当前策略 | $R + \gamma \max_{a'} Q(S', a')$ |
| 探索的影响 |          受探索行为影响，更保守           |     不受探索影响，直接学最优     |
|  收敛目标  |            当前策略的 $q_\pi$             |         最优策略的 $q^*$         |

---

### 7. DP 与 TD 的对应关系

|          Bellman 方程           | Full Backup（DP） | Sample Backup（TD） |
| :-----------------------------: | :---------------: | :-----------------: |
| Bellman Expectation for $v_\pi$ | Policy Evaluation |     TD Learning     |
| Bellman Expectation for $q_\pi$ | Policy Iteration  |      **SARSA**      |
|  Bellman Optimality for $q^*$   |  Value Iteration  |   **Q-Learning**    |

其中更新规则统一写作 $x \xleftarrow{\alpha} y$，即 $x \leftarrow x + \alpha(y - x)$：

- TD Learning：$V(S) \xleftarrow{\alpha} R + \gamma V(S')$
- SARSA：$Q(S,A) \xleftarrow{\alpha} R + \gamma Q(S', A')$
- Q-Learning：$Q(S,A) \xleftarrow{\alpha} R + \gamma \max_{a'} Q(S', a')$

Q-Learning 本质上是 Value Iteration 的采样版本。

---

### 8. Take-home lessons

- 无模型方法用**采样**替代模型中的期望计算
- MC 从完整 episode 学习；TD 每步都可更新，可用于 continuing 环境
- MC 零偏差高方差；TD 有偏差低方差，通常效率更高
- 收敛通常需要 GLIE 采样策略
- On-policy 方法用同一策略采样和学习（SARSA）；off-policy 方法的采样策略与学习策略可以不同（Q-Learning）
- SARSA 和 Q-Learning 是学习 $q$ 函数的基础 TD 方法
