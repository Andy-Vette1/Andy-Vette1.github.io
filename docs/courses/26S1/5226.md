## Week 3 Intro to RL; Bellman equations, policy and value Iteration    

### 整体脉络

本节课核心问题：**在已知模型（P 和 R）的情况下，如何找到最优策略？**

逻辑链：MDP 定义问题 → Bellman 方程描述价值 → Policy / Value Iteration 求解最优策略

---

### 1. MDP 是什么？

MDP（Markov Decision Process，马尔可夫决策过程）是 RL 的基础建模框架，由五元组 $(S, A, P, R, \gamma)$ 定义：

- $S$：有限状态集合
- $A$：有限动作集合
- $P^a_{s,s'} = P[S_{t+1}=s' \mid S_t=s, A_t=a]$：转移概率矩阵
- $R^a_s = \mathbb{E}[R_{t+1} \mid S_t=s, A_t=a]$：期望即时奖励函数（依赖状态和动作，不是集合）
- $\gamma \in [0,1]$：折扣因子

**关于 $\gamma$ 的直觉：**

- $\gamma$ 接近 0：agent 只看重当前的即时奖励，短视
- $\gamma$ 接近 1：agent 重视长期回报，有远见

**策略**（Policy）是从状态到动作的映射：

- 确定性策略：$a = \pi(s)$
- 随机策略：$\pi(a \mid s) = P[\text{Action}=a \mid \text{State}=s]$

---

### 2. 两种价值函数

**状态价值函数** $v_\pi(s)$：从状态 $s$ 出发，按策略 $\pi$ 行动，期望能获得的总折扣回报。

$$v_\pi(s) = \mathbb{E}_\pi[G_t \mid S_t = s]$$

**状态-动作价值函数** $q_\pi(s, a)$：在状态 $s$ **先执行动作 $a$** ，之后再按策略 $\pi$ 行动，期望能获得的总折扣回报。

$$q_\pi(s, a) = \mathbb{E}_\pi[G_t \mid S_t = s, A_t = a]$$

**关键区别**：$q_\pi(s,a)$ 比 $v_\pi(s)$ 多指定了一个动作 $a$。

**两者的关系**：$v_\pi(s)$ 是 $q_\pi(s,a)$ 对所有动作按策略概率的加权平均：

$$v_\pi(s) = \sum_a \pi(a \mid s) \cdot q_\pi(s, a)$$

---

### 3. Bellman 期望方程

Bellman 方程把价值函数递归分解为**即时奖励**和**折扣后的未来价值**两部分。

**对状态价值函数：**

$$v_\pi(s) = \mathbb{E}\left[R_{t+1} + \gamma v_\pi(S_{t+1}) \mid S_t = s\right]$$

展开期望：

$$v_\pi(s) = \sum_a \pi(a \mid s) \left[ R^a_s + \gamma \sum_{s'} P^a_{s,s'} v_\pi(s') \right]$$

逐项含义：

- $R^a_s$：执行动作 $a$ 后立刻获得的即时奖励
- $v_\pi(S_{t+1})$：到达下一状态后，继续按 $\pi$ 行动的总价值
- $\gamma$：对未来价值打折扣
- $\mathbb{E}[\cdot]$：因为转移是随机的，所以取期望

**对状态-动作价值函数：**

$$q_\pi(s, a) = \mathbb{E}\left[R_{t+1} + \gamma q_\pi(S_{t+1}, A_{t+1}) \mid S_t=s, A_t=a\right]$$

**闭式解（矩阵形式）：**

$$v_\pi = R^\pi + \gamma P^\pi v_\pi \implies v_\pi = (I - \gamma P^\pi)^{-1} R^\pi$$

实践中状态空间过大，矩阵求逆不可行，需用迭代方法。

---

### 4. 最优价值函数与 Bellman 最优方程

"解 MDP"等价于找到最优策略，即找使价值函数最大的策略：

$$v^*(s) = \max_\pi v_\pi(s), \quad q^*(s,a) = \max_\pi q_\pi(s,a)$$

**关键结论** ：最优策略就是对 $q^*$ 贪心：

$$
\pi^*(a \mid s) =
\begin{cases}
1, & \text{if } a = \arg\max_{a'} q^*(s, a') \\\\
0, & \text{otherwise}
\end{cases}
$$

且最优策略**一定存在确定性的形式**。

**Bellman 最优方程：**

$$v^*(s) = \max_a \left[ R^a_s + \gamma \sum_{s'} P^a_{s,s'} v^*(s') \right]$$

$$q^*(s,a) = R^a_s + \gamma \sum_{s'} P^a_{s,s'} \max_{a'} q^*(s', a')$$

**与期望方程的关键区别**：

| | Bellman 期望方程 | Bellman 最优方程 |
|:---:|:---:|:---:|
| 对动作的处理 | $\sum_a \pi(a\|s)$（按策略加权平均）| $\max_a$（直接取最大值）|
| 用途 | 评估某个策略的好坏 | 寻找最优策略 |
| 是否线性 | 线性，有闭式解 | 非线性，无闭式解，必须迭代 |

---

### 5. Policy Iteration（策略迭代）

**思路**：交替做两件事，直到策略不再变化。

1. **Policy Evaluation**：固定当前策略 $\pi$，反复用 Bellman 期望方程迭代，直到 $v_\pi$ 收敛
2. **Policy Improvement**：根据 $v_\pi$ 做 greedy 改进，得到新策略 $\pi' = \text{greedy}(v_\pi)$
3. 用新策略 $\pi'$ 回到第一步，循环直到策略收敛到 $\pi^*$

Policy Improvement 保证每次新策略一定不差于旧策略，因此保证收敛到 $\pi^*$。

---

### 6. Value Iteration（价值迭代）

**思路**：把 Policy Iteration 中的 Evaluation 步骤压缩为只做一步，直接用 Bellman 最优方程迭代价值函数。

$$v_{k+1}(s) = \max_a \left[ R^a_s + \gamma \sum_{s'} P^a_{s,s'} v_k(s') \right]$$

收敛后从 $v^*$ 推出最优策略，**过程中没有显式的策略**。

---

### 7. Policy Iteration vs Value Iteration

| | Policy Iteration | Value Iteration |
|:---:|:---:|:---:|
| 起点 | 随机策略 | 随机价值函数 |
| 优化对象 | 策略 $\pi$ | 价值函数 $v$ |
| 每轮工作量 | 大（需完整 Evaluation）| 小（一步更新）|
| 收敛轮数 | 少 | 多 |
| 算法复杂度 | 较复杂 | 较简单 |
| 是否需要模型 | 需要 $P$ 和 $R$ | 需要 $P$ 和 $R$ |

两者都是 **model-based** 方法，都需要已知转移矩阵 $P$ 和奖励函数 $R$。这是它们共同的局限性，也是引出 model-free 方法（MC、TD、SARSA、Q-Learning）的动机。

---

### 8. Take-home lessons

- MDP 是 RL 最基础的建模框架，MDP = MRP + 动作
- 状态价值函数描述状态有多好，状态-动作价值函数描述在某状态做某动作有多好
- 找最优策略等价于找使价值函数最大的策略
- Bellman 期望方程是线性的，有闭式解；Bellman 最优方程是非线性的，必须迭代求解
- Policy Iteration 和 Value Iteration 都需要完整模型（P, R），属于 model-based 方法
- 最优策略一定可以写成确定性的贪心策略

## Week 4 SARSA, Q-learning

### 整体脉络

本节课核心问题：**在不知道模型（P 和 R）的情况下，如何找到最优策略？**

分两步推进：

- **Step 1**：从 model-based prediction → model-free prediction（用采样替代转移矩阵）
- **Step 2**：从 model-free prediction → model-free control（用 Q 函数替代 V 函数）

---

### 1. 为什么需要无模型方法？

Model-based 方法的策略更新需要已知奖励函数 $R$ 和转移概率 $P$：

$$v'(s) \to \max_{a \in A} \left[ R^a_s + \gamma \sum_{s' \in S} P^a_{s,s'} v_{s'} \right]$$

现实中 $R$ 和 $P$ 往往未知。

**解决方案**：用**采样**替代求期望，不再需要 $P$。

---

### 2. MC vs TD（预测层面）

两者都是无模型预测，区别在于用什么来作为更新目标。

|                      |                    Monte-Carlo                    |                                   TD(0)                                   |
| :------------------: | :-----------------------------------------------: | :-----------------------------------------------------------------------: |
|       更新目标       |         完整回报 $G_t$（等 episode 结束）         |                  单步估计 $R_{t+1} + \gamma V(S_{t+1})$                   |
|       更新公式       | $V(S_t) \leftarrow V(S_t) + \alpha(G_t - V(S_t))$ | $V(S_t) \leftarrow V(S_t) + \alpha(R_{t+1} + \gamma V(S_{t+1}) - V(S_t))$ |
|     偏差 / 方差      |                  零偏差，高方差                   |                              有偏差，低方差                               |
| 是否需要完整 episode |                       必须                        |                                  不需要                                   |
|       适用环境       |               仅 episodic（有终止）               |                          episodic 或 continuing                           |

TD 括号内的量 $\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$ 称为 **TD error**，是整个 TD 系列算法的核心。

---

### 3. 从预测到控制：为什么用 Q 而不用 V？

基于 $V(s)$ 的 greedy 策略改进仍然需要模型：

$$\pi'(s) = \arg\max_{a \in A} \left[ R^a_s + P^a_{s,s'} V(s') \right] \quad \text{（仍需 } R \text{ 和 } P \text{）}$$

改用 **$Q(s,a)$** 可以完全绕开模型：

$$\pi'(s) = \arg\max_{a \in A} Q(s, a) \quad \text{（model-free）}$$

因此控制问题转化为：**如何学到 Q 函数？**

---

### 4. SARSA（On-Policy TD Control）

SARSA 是 on-policy 的 TD 控制算法，名称来自其使用的五元组 $(S, A, R, S', A')$。

**更新公式：**

$$Q(S,A) \leftarrow Q(S,A) + \alpha \left[ R + \gamma Q(S', A') - Q(S,A) \right]$$

**算法流程：**

1. 初始化 $Q$ 表，令 $Q(\text{terminal}, \cdot) = 0$
2. 初始化状态 $S$，用 $\varepsilon$-greedy 从 $Q$ 选择动作 $A$
3. 执行 $A$，观察 $R$、$S'$
4. 从 $S'$ 用 $\varepsilon$-greedy 选择 $A'$
5. 用上式更新 $Q(S, A)$
6. $S \leftarrow S'$，$A \leftarrow A'$，回到步骤 3，直到 $S$ 为终止态

关键点：$A'$ 是按**当前策略**（$\varepsilon$-greedy）在 $S'$ 上选出的，因此是 on-policy。

**收敛条件（需同时满足）：**

- GLIE 策略序列：既保证无限探索，又最终收敛为贪心策略
- Robbins-Monro 步长条件：$\sum_t \alpha_t = \infty$，$\sum_t \alpha_t^2 < \infty$

---

### 5. Q-Learning（Off-Policy TD Control）

Q-Learning 是 off-policy 的 TD 控制算法。

**更新公式：**

$$Q(S,A) \leftarrow Q(S,A) + \alpha \left[ R + \gamma \max_{a'} Q(S', a') - Q(S,A) \right]$$

**与 SARSA 的核心区别**：更新时 $S'$ 处不使用实际执行的动作，而是直接取最大值。

**算法流程：**

1. 初始化 $Q$ 表，令 $Q(\text{terminal}, \cdot) = 0$
2. 初始化状态 $S$
3. 用 $\varepsilon$-greedy 选择动作 $A$，执行后观察 $R$、$S'$
4. 用上式更新 $Q(S, A)$
5. $S \leftarrow S'$，回到步骤 3，直到 $S$ 为终止态

- **行为策略**（实际执行）：$\varepsilon$-greedy，保证探索
- **目标策略**（更新用）：greedy（直接取 $\max$）

两个策略不同，因此是 off-policy。Q-Learning 收敛到最优 $q^*$。

---

### 6. SARSA vs Q-Learning 对比

|            |                   SARSA                   |            Q-Learning            |
| :--------: | :---------------------------------------: | :------------------------------: |
|  策略类型  |                 On-policy                 |            Off-policy            |
|  更新目标  | $R + \gamma Q(S', A')$，$A'$ 来自当前策略 | $R + \gamma \max_{a'} Q(S', a')$ |
| 探索的影响 |          受探索行为影响，更保守           |     不受探索影响，直接学最优     |
|  收敛目标  |            当前策略的 $q_\pi$             |         最优策略的 $q^*$         |

---

### 7. DP 与 TD 的对应关系

|          Bellman 方程           | Full Backup（DP） | Sample Backup（TD） |
| :-----------------------------: | :---------------: | :-----------------: |
| Bellman Expectation for $v_\pi$ | Policy Evaluation |     TD Learning     |
| Bellman Expectation for $q_\pi$ | Policy Iteration  |      **SARSA**      |
|  Bellman Optimality for $q^*$   |  Value Iteration  |   **Q-Learning**    |

其中更新规则统一写作 $x \xleftarrow{\alpha} y$，即 $x \leftarrow x + \alpha(y - x)$：

- TD Learning：$V(S) \xleftarrow{\alpha} R + \gamma V(S')$
- SARSA：$Q(S,A) \xleftarrow{\alpha} R + \gamma Q(S', A')$
- Q-Learning：$Q(S,A) \xleftarrow{\alpha} R + \gamma \max_{a'} Q(S', a')$

Q-Learning 本质上是 Value Iteration 的采样版本。

---

### 8. Take-home lessons

- 无模型方法用**采样**替代模型中的期望计算
- MC 从完整 episode 学习；TD 每步都可更新，可用于 continuing 环境
- MC 零偏差高方差；TD 有偏差低方差，通常效率更高
- 收敛通常需要 GLIE 采样策略
- On-policy 方法用同一策略采样和学习（SARSA）；off-policy 方法的采样策略与学习策略可以不同（Q-Learning）
- SARSA 和 Q-Learning 是学习 $q$ 函数的基础 TD 方法

## Week 5 Deep Q

### 1. 为什么需要 Deep RL？
- **状态空间爆炸**：简单grid world 625个状态，加上更多元素后状态数指数增长（Backgammon: 10²⁰, Go: 10¹⁷⁰）
- **连续状态空间**：如CartPole的状态是连续值（位置、速度、角度、角速度），无法用Q-table存储
- **泛化需求**：Q-table在新地图上无法复用已学知识

### 2. 核心思想：Value Function Approximation
- 用**函数**代替Q-table来近似Q值
- 三种形式：
  - V̂(s, w)：状态 → 价值
  - Q̂(s, a, w)：状态+动作 → Q值
  - Q̂(s, ·, w)：状态 → 所有动作的Q值（**DQN采用这种**）

### 3. DQN 算法要点

#### 神经网络替代Q-Table
- 输入：状态向量（或图像像素）
- 输出：每个动作对应的Q值
- 通过反向传播+梯度下降来更新网络权重

#### Loss函数
- Loss = (预测的Q值 - TD-target)²
- TD-target = r + γ · max_a' Q̂(s', a')

#### Experience Replay（经验回放）
- 将transition (s, a, r, s', done) 存入环形缓冲区
- 训练时从缓冲区**随机采样mini-batch**
- 打破数据间的时间相关性，稳定训练
- 属于**off-policy**方法

#### Target Network（目标网络）
- 使用**两个网络**：Prediction Network（主网络）和 Target Network（目标网络）
- Target Network用于计算TD-target，参数每隔C步从主网络复制
- 避免"追逐移动目标"导致的训练不稳定

### 4. Atari游戏中的DQN
- **输入处理**：灰度化 + 缩放到84×84 + 堆叠4帧（编码运动信息）
- **网络结构**：卷积层（保留空间信息）→ 全连接层 → 输出各动作Q值
- 端到端学习：直接从像素到动作

### 5. 实用技巧
- **状态加噪声**：离散/稀疏状态（如one-hot）配合ReLU容易产生"死神经元"，加小噪声缓解
- `state = state.reshape(1,k) + np.random.rand(1,k)/c`

### 6. DQN之后的发展
Double DQN → Duelling DQN → Prioritized Replay → Rainbow → IQN → Munchausen RL 等

## Week 6 Introduction to Game Theory 

### 1. 博弈的严格定义 (Defining Games)
一个有限的 $n$ 人博弈可以由三元组 $(N, A, u)$ 来定义：

- **$N$ (Players)**：有限的玩家集合，索引为 $i$。
- **$A$ (Action Space)**：动作空间，是所有玩家动作集的笛卡尔积 $A = A_1 \times \dots \times A_n$。
    - $a \in A$ 被称为动作组合 (Action Profile) 或联合动作。
- **$u$ (Utility Function)**：效用函数集合 $u = \langle u_1, \dots, u_n \rangle$。
    - 对于每个玩家 $i$，效用函数 $u_i: A \mapsto \mathbb{R}$ 将一个联合动作映射为一个实数值。

### 2. 效用理论与公理 (Utility Theory)
效用函数是基于智能体对结果的偏好关系（如 $O_1 > O_2$）建立的。冯·诺依曼和摩根斯顿证明，若偏好满足以下六大公理，则存在效用函数：

1. **完备性 (Completeness)**：任何两个结果之间都存在确定的偏好关系。
2. **传递性 (Transitivity)**：若 $o_1 > o_2$ 且 $o_2 > o_3$，则 $o_1 > o_3$。
3. **单调性 (Monotonicity)**：玩家总是偏好获得更好结果概率更高的博弈。
4. **可分解性 (Decomposability)**：复合博弈可以简化为等价的简单博弈。
5. **可替代性 (Substitutability)**：无差异的结果可以在博弈中互相替换。
6. **连续性 (Continuity)**：存在某个概率使得中间结果等价于最好和最差结果的概率组合。

**结论**：理性的智能体会选择最大化其期望效用值的动作。

### 3. 经典博弈分类与模型
博弈论提供了一个“模型库”，用于封装典型的互动场景：

#### A. 纯竞争博弈 (Pure Competition)
- **定义**：玩家利益完全对立，效用之和为常数（零和博弈是其特殊情况）。
- **典型例子**：
    - **匹配硬币 (Matching Pennies)**：一方想相同，一方想不同。
    - **石头剪刀布 (Rock-Paper-Scissors)**：循环克制关系。
    - **猜拳游戏 (Morra)**：涉及隐藏信息与数值猜测。

#### B. 非零和博弈 (Non-zero-sum)
- **囚徒困境 (Prisoner's Dilemma)**：反映了个体理性（背叛）与集体理性（合作）之间的冲突。
    - **TCP回退博弈**：网络协议中，自私不回退（背叛）会导致整体网络瘫痪。
- **协调博弈 (Coordination Games)**：玩家利益一致，核心在于达成共识。
    - **交通博弈 (Traffic Game)**：选择靠左还是靠右行驶。
- **性别之战 (Battle of the Sexes)**：结合了合作（想在一起）与竞争（对活动偏好不同）。

### 4. 博弈论 (GT) 与 强化学习 (RL) 术语对比

| 博弈论 (GT) | 强化学习 (RL) |
| :--- | :--- |
| 玩家 (Player) | 智能体 (Agent) |
| 动作 (Action) | 动作 (Action) |
| 效用/收益 (Payoff) | 奖励 (Reward) |
| 策略 (Strategy) | 策略 (Policy) |
| 动作组合 (Action Profile) | 联合动作 (Joint Action) |

**核心差异**：
- **状态性**：经典博弈论通常是无状态的（Stateless），而 RL 奖励取决于环境状态。
- **延迟性**：GT 的收益通常是即时的，而 RL 的奖励可能存在延迟且具   有累积性。

你的总结可以改成这样

帕累托最优关注的是一个结果是否还能被“无损改进”。如果不存在另一个结果能让至少一个玩家变好，同时不让任何玩家变差，那么这个结果就是帕累托最优。它不等于总收益最大，也不一定公平。有限博弈通常至少有一个帕累托最优结果。

纳什均衡关注的是策略组合是否稳定。判断方法是固定一方策略，找另一方的 best response；再反过来固定另一方策略，找这一方的 best response。如果某个策略组合里，双方都是对对方策略的 best response，那么这个策略组合就是纳什均衡。纳什均衡不一定是帕累托最优。

在囚徒困境里，双方背叛是纳什均衡，因为任何一方单方面改成合作都会变差；但它不是帕累托最优，因为双方合作会让两个人都更好。

## Week 8 & 9: Population Games and Evolutionary Game Theory

### 1. 本节课概览

这节课要解决的核心问题是:**当多智能体系统不再由"理性玩家精算最优解"驱动,而是由大量同质 agent 在一个群体中相互作用时,系统的行为如何演化?最终会稳定在哪里?**

这是从经典博弈论(Week 6-7)向多智能体学习(本课的最终目标)过渡的关键一节。课程的逻辑线是:

经典博弈论假设玩家是理性的、信息完全的、计算无限的——这在现实多智能体系统(尤其是生物群体、大规模分布式系统、学习型 agent)中往往不成立。**进化博弈论 (Evolutionary Game Theory, EGT)** 提供了一个替代框架:不要求理性,只要求"做得好的策略会在群体中扩散"——而这恰好是**强化学习**在做的事情。

所以这节课的另一条暗线是:**EGT 是连接"群体演化"与"多智能体强化学习"的理论桥梁**。课程最后通过 Cross-Learning 的例子,正式把这两个看似无关的领域连接起来。

### 2. 核心概念

#### 2.1 群体博弈 (Population Game)

**中文解释**:在大量**不可区分的**玩家组成的群体中进行的博弈。所有玩家共享相同的策略集, **重要的不是"谁"在玩什么策略,而是"群体中各策略的占比是多少"** 。

**关键性质**:
- 玩家匿名、可互换 (interchangeable, indistinguishable)
- 所有玩家有相同的策略集
- 游戏关心的是**频率分布**,不是个体身份

**作用**:这是整个 EGT 的基础设定。它把"两个具体玩家相互博弈"扩展成"一个群体的状态演化"。

#### 2.2 拥塞博弈 (Congestion Game) 和势博弈 (Potential Game)

**中文解释**:
- **拥塞博弈**:每个玩家选择一组资源(策略),每个资源的延迟随使用人数单调递增
- **势博弈**:存在一个全局势函数 $P$,使得任何玩家单方面改变策略导致的收益变化等于势函数的变化

**两个关键定理**(课件给出):
1. 每个有限势博弈都有**纯策略 Nash 均衡**
2. 每个拥塞博弈都是势博弈

**直觉理解**:势博弈像一个"地形",每个 agent 都在沿坡下滑,系统最终会停在某个局部最低点(Nash)。

**Myopic Best-Response 算法**:每轮让某个偏离了最优响应的 agent 切换到最优响应。在势博弈中**总会终止于 Nash**,但在一般博弈里可能死循环。

#### 2.3 Anarchy 的代价 (Price of Anarchy)

**中文解释**:由于缺乏中心协调,自私博弈达到的 Nash 均衡相对于"社会最优"的损失。

定义为:Nash 均衡下的总损失 / 社会最优下的总损失。

**囚徒困境的例子**:
- 中心协调能让两人都拿 -1(总和 -2)
- Nash 均衡是 (D,D),总和 -6
- Price of Anarchy = 6/2 = 3(课件给出 2/6,这是反过来的取法)

#### 2.4 Braess 悖论 (Braess' Paradox)

**中文解释**:在路网中**增加一条容量更大的边,反而可能让所有人花费更多时间**。这个反直觉现象说明 Nash 均衡**不一定是 pro-social**(对集体有利)。

**课件的具体例子**:4000 名玩家,有边时所有人走中间捷径 → 80 分钟;移除中间边后分流 → 65 分钟。

**作用**:这是 EGT 出场的一个重要动机——理性的 Nash 均衡可能产生集体灾难,我们需要其他工具来分析"实际上会发生什么"。

#### 2.5 Cross-Learning(交叉学习)

**中文解释**:最简单的强化学习形式之一,**无状态 (stateless)** 设定:
- 每个 player 维护一个 action 概率分布 $P_j$
- 玩了 action $j$、对手玩了 $k$、获得效用 $U^R_{jk} \in [0,1]$ 后,更新规则:

$$P_j(n+1) = U^R_{jk} + (1 - U^R_{jk}) \cdot P_j(n)$$
$$P_{j'}(n+1) = (1 - U^R_{jk}) \cdot P_{j'}(n) \quad \text{对所有} j' \neq j$$

**直觉**:实际执行的 action 概率被"插值拉向 1",拉的力度正比于 payoff;其他 action 的概率按比例缩小。

**作用**:这是课件中**唯一被明确证明"等价于 replicator dynamics"的 RL 算法**(在期望意义下、连续时间极限下)。它是这节课串起 EGT 和 RL 的核心桥梁。

**重要限制**:Cross-Learning 是**个体学习**(individual learning)——agent 只从自己的经历学习,不模仿他人。

#### 2.6 进化博弈论 (Evolutionary Game Theory) 的核心假设

EGT 与经典博弈论的关键区别(课件总结):

| 经典 GT | EGT |
|---|---|
| 个体玩家(通常 2 人) | 群体层面思考 |
| 单次博弈 | 重复博弈 |
| 确定性 | 随机过程 |
| 假设理性 | 不要求理性 |
| 完全信息 | 不要求完全信息 |
| 玩家有意识地选择 | 修订协议 (revision protocol) 自动驱动 |

**核心隐喻**(Maynard Smith):"Let nature do the work and see what happens" — 让自然选择代替理性思考,结果**看起来好像** agent 是理性 fitness 最大化者,但这**不是设计出来的**。

#### 2.7 对称博弈 (Symmetric Games)

**中文解释**:玩家可互换的博弈,等价于 $a_{ij} = b_{ji}$,即 $A = B^T$。

**关键事实**(课件):**每个对称博弈都有对称 Nash 均衡**。

**对称 Nash 的形式**:策略 $x$ 是对称 Nash 当且仅当对所有其他策略 $z$:
$$x^T A x \geq z^T A x$$

**为什么 EGT 偏爱对称博弈**:因为群体中 agent 不可区分,博弈必须对玩家角色保持中立。

#### 2.8 进化稳定策略 (Evolutionarily Stable Strategy, ESS)

**中文解释**:一个群体中所有人都使用的策略 $P$,如果**任何小比例的突变体 $Q$ 都无法入侵**(自然选择会把它们淘汰),则 $P$ 是 ESS。

**形式定义**(两个条件):
1. **Nash 条件**:$\Pi(P,P) \geq \Pi(Q,P)$ 对所有 $Q$ 成立
2. **稳定条件**:若 $\Pi(P,P) = \Pi(Q,P)$,则必须 $\Pi(P,Q) > \Pi(Q,Q)$ 对所有 $Q \neq P$ 成立

**等价形式**(线性插值):$\Pi(P, \epsilon Q + (1-\epsilon)P) > \Pi(Q, \epsilon Q + (1-\epsilon)P)$ 对所有 $Q \neq P$、足够小的 $\epsilon$。

**直觉**:即使 $P$ 和 $Q$ 在"全 $P$ 群体"里平手,只要有少量 $Q$ 涌入,$P$ 就必须重新占优——否则 $Q$ 会逐渐扩散。

**ESS 与 Nash 的关系**(课件 Venn 图):
$$\text{Strict Nash} \subset \text{ESS} \subset \text{Nash}$$

**ESS 存在性定理**(课件 slide 39):若一个 2 玩家对称博弈有两个纯策略 $s_1, s_2$,且
$$\Pi(s_1,s_1) \neq \Pi(s_2,s_1) \wedge \Pi(s_2,s_2) \neq \Pi(s_1,s_2)$$
则该博弈有 ESS。

#### 2.9 复制动力学 (Replicator Dynamics)

**中文解释**:描述群体中各策略类型频率随时间演化的微分方程系统。"复制"指的是**精确复制行为,复制速度正比于 fitness**。

**核心方程**:
$$\dot{x}_i = x_i\big((Ax)_i - x^T A x\big)$$

其中:
- $x_i$:类型 $i$ 在群体中的频率
- $x = (x_1, ..., x_n) \in S_n$:群体状态(单纯形上的一个点)
- $(Ax)_i$:类型 $i$ 的平均 payoff
- $x^T A x$:群体平均 payoff
- $\dot{x}_i / x_i$:类型 $i$ 的人均增长率

**口语化表述**:"$x_i$ 增长率 = 它比平均做得好多少"

**重要性质**:
- 给 $A$ 的某一列加常数,**rest points 不变**(因为这相当于给所有人遇到该类型时统一加分)
- 它是**确定性**动力学(虽然底层假设是随机选择,但取大群体极限后是确定性 ODE)

**关键限制**(课件明确指出):**只能处理离散的、不可变的策略类型**——它不能凭空产生新策略,只能调整已有策略的占比。

#### 2.10 Rest Points(平衡点)

**中文解释**:$\dot{x}_i = 0$ 的状态。从复制方程看,这有两种情况:
1. $x_i = 0$:这种类型已经灭绝
2. $(Ax)_i = x^T A x$:类型 $i$ 的 payoff 等于群体平均 payoff

**关键事实**(课件 slide 43, 55):**在稳态下,所有"还活着"的类型 payoff 必须相等**——否则高 payoff 类型会继续扩张,不算稳态。

#### 2.11 进化博弈论的"Folk Theorem"

(课件 slide 54, 56)

复制动力学下三个核心结论:
1. **稳定的 rest points 都是 Nash 均衡**
2. **如果动力学收敛,就收敛到 Nash 均衡**
3. **严格 Nash 均衡是吸引子**(attractor)

注意反向不成立:Nash 均衡不一定稳定;不一定每个动力学都收敛(可能进入极限环,如石头剪刀布)。

#### 2.12 Adaptive Dynamics(补充框架)

**中文解释**:用于处理**连续策略空间**的演化框架(因为 replicator 处理不了连续 trait)。

**关键假设**:
- 群体在大部分时间是单态的 (monomorphic):所有玩家用同一策略
- 突变罕见,且突变体策略接近驻地策略
- 突变体如果 fitness 更高就**全面接管**,否则被淘汰

**关键公式**:
- Invasion fitness: $f_x(y) = P(y, x) - P(x, x)$
- Adaptive Dynamics: $\dot{x} = \frac{dD(x,y)}{dx}\big|_{x \to y}$

**作用**:能解释**分支现象** (branching) — 群体如何从单态分裂成多态。但分支之后的演化它处理不了。

### 3. 概念之间的关系

整节课的概念图大致如下:

**起点(经典博弈论的局限)**:Nash 均衡不一定 pro-social(Braess 悖论)、计算上不实际、需要理性假设。

**第一层重构 — 群体视角**:把"两个具体玩家"换成"大群体"→ 群体博弈 → 拥塞博弈是其特例 → 势博弈给出可达性保证(myopic best-response 收敛)。

**第二层重构 — 学习视角**:从两个角度引入"学习":
- **个体学习** (Cross-Learning):agent 从自己的 reward 调整策略
- **社会学习** (Social Learning):agent 模仿群体中成功者

**EGT 的核心叙事**:把"学习"重新解释为"自然选择"——做得好的策略复制得快。这导出两个核心工具:
- **静态工具**:ESS — 描述"什么样的策略组合能稳定存在"
- **动态工具**:Replicator Dynamics — 描述"群体如何演化到 ESS"

**ESS 与 Nash 的关系**:ESS 是 Nash 的精化(refinement),strict Nash 又是 ESS 的精化:
$$\text{Strict Nash} \subset \text{ESS} \subset \text{Nash}$$

**Replicator 与 Nash 的关系**(Folk Theorem):稳定 rest points $\subseteq$ Nash;严格 Nash 是吸引子。

**RL 与 EGT 的连接**:Cross-Learning 在连续时间极限下、在期望意义下,**与 replicator dynamics 服从相同的方程**。这意味着:个体学习和社会学习在数学上同构,可以用同一套工具分析。

**扩展**:
- 当策略离散且数量 = 2:三种行为(支配 / 双稳态 / 稳定共存)
- 当 $n = 3$:可能出现极限环(石头剪刀布)
- 当策略连续:replicator 不够用,需要 Adaptive Dynamics

### 4. 关键公式 / 算法 / 模型

#### 4.1 Cross-Learning 更新规则

$$P_j(n+1) = U^R_{jk} + (1 - U^R_{jk}) \cdot P_j(n)$$
$$P_{j'}(n+1) = (1 - U^R_{jk}) \cdot P_{j'}(n) \quad \forall j' \neq j$$

- $j$:实际执行的 action
- $k$:对手执行的 action
- $U^R_{jk}$:玩家 R 在 $(j,k)$ 下获得的归一化效用 $\in [0,1]$

**解决什么问题**:最简化的 stateless RL,用于研究"不会推理的 agent 反复博弈会学出什么"。

**何时用**:课件中作为推导 replicator-RL 等价性的工具。

#### 4.2 Replicator 方程

$$\dot{x}_i = x_i\big((Ax)_i - x^T A x\big)$$

**符号**:
- $A$:对称博弈的 payoff 矩阵
- $x$:群体状态(频率向量)
- $S_n$:$n$ 维单纯形(所有合法的频率分布)

**解决什么问题**:在不需要假设 agent 理性的前提下,描述策略频率如何随时间演化、最终会收敛到哪。

**何时用**:对称博弈中分析群体长期行为;预测哪种策略会主导;判断是否存在共存平衡。

#### 4.3 $n=2$ 情形的 Replicator(简化形式)

任何 $2 \times 2$ 对称博弈可经"列归一化"简化为:
$$A = \begin{pmatrix} 0 & a \\ b & 0 \end{pmatrix}$$

设 $x_1 = x$, $x_2 = 1-x$,则:
$$\dot{x} = x(1-x)\big[a - (a+b)x\big]$$

**Rest points**:
- $x = 0$(全是 type 2)
- $x = 1$(全是 type 1)
- $x^* = \frac{a}{a+b}$(内部混合点,需 $ab > 0$ 才存在)

**三种定性行为**(课件 slide 45):
1. **Dominance(支配)**:一个策略碾压另一个,系统流向一个边界
2. **Bistability(双稳态)**:两个边界都稳定,内部点不稳定 — 协调博弈典型行为
3. **Stable Coexistence(稳定共存)**:内部点稳定,两个边界都不稳定 — 鹰鸽博弈

#### 4.4 ESS 条件(两种等价形式)

**形式 1**:
1. $\Pi(P,P) \geq \Pi(Q,P)$ 对所有 $Q$
2. 若条件 1 取等,则 $\Pi(P,Q) > \Pi(Q,Q)$ 对所有 $Q \neq P$

**形式 2**(线性插值形式):
$$\Pi(P, \epsilon Q + (1-\epsilon)P) > \Pi(Q, \epsilon Q + (1-\epsilon)P)$$
对所有 $Q \neq P$、足够小的 $\epsilon$ 成立。

#### 4.5 Adaptive Dynamics(连续策略框架)

$$\dot{x} = \frac{dD(x,y)}{dx}\bigg|_{x \to y}$$

**Invasion fitness**: $f_x(y) = P(y, x) - P(x, x)$

**奇异点 $x^\star$ 的稳定性条件**(以 snowdrift 类博弈 $P(x,y) = B(x+y) - C(x)$ 为例):
- **收敛稳定** (convergent stable):$2B''(2x^\star) - C''(x^\star) < 0$
- **演化不稳定**(可能分支):$B''(2x^\star) - C''(x^\star) > 0$

**不确定是否重点**:这部分是课件后半段补充内容,可能是为下周(Snowdrift / 社会困境)做铺垫,不一定是本周考试重点。

### 5. 例子

#### 5.1 Selfish Routing(自私路由)

(课件 slide 5-6, 11)

两条路 A 和 B,2 个玩家。Cost matrix 显示玩家分流时各拿低 cost,扎堆时双方都付高 cost。Nash 均衡是 (A,B) 和 (B,A) — 这里 Nash 恰好是 pro-social。

#### 5.2 Braess 悖论(4000 玩家)

(课件 slide 12-13)

- **有捷径时**:所有人挤捷径 → Nash 是 4000 人都走 svwt → 80 分钟
- **拆掉捷径**:玩家被迫分流 svt 和 swt 各 2000 人 → 65 分钟

**结论**:Nash 不一定是 pro-social,有时候**移除选项反而对集体有利**。

#### 5.3 Car Park Problem(交叉学习的实证案例)

(课件 slide 17)

车场 A 远但大(延迟 $n$ 分钟),车场 B 近但小(延迟 $5n$ 分钟)。从 1000 步到 $10^6$ 步的 Cross-Learning 模拟显示:个体策略概率从均匀逐渐分化成两群,一群趋向 1(总选 A),一群趋向 0(总选 B)。这就是群体在没有协调的情况下,通过个体学习"自动"达到的混合均衡。

#### 5.4 Body Size Game(甲虫体型博弈)

(课件 slide 32-35)

| | Small | Large |
|---|---|---|
| **Small** | 5, 5 | 1, 8 |
| **Large** | 8, 1 | 3, 3 |

**入侵分析**:
- 大甲虫主导的群体里,小突变体 fitness ≈ 1,大甲虫 fitness ≈ 3 → 小入侵失败,**Large 是 ESS**
- 小甲虫主导的群体里,大突变体 fitness ≈ 8,小甲虫 fitness ≈ 4 → 小**不是** ESS

虽然 (Small, Small) 总福利 (5+5=10) 高于 (Large, Large) (3+3=6),但群体仍演化到 Large — 又一个 Nash 不 pro-social 的例子。

#### 5.5 Hawk-Dove Game(鹰鸽博弈,稳定共存的典型)

(课件 slide 46-47)

| | Hawk | Dove |
|---|---|---|
| **Hawk** | $(G-C)/2$ | $G$ |
| **Dove** | $0$ | $G/2$ |

当 $C > G$(伤害成本大于增益)时,内部混合点 $x^* = G/C$ 是 ESS — **群体中"鹰"的稳定比例**。这是 stable coexistence 的范例。

#### 5.6 Rock-Scissors-Paper / 侧斑蜥蜴

(课件 slide 50-53)

蜥蜴有三种雄性形态(orange / blue / yellow),它们的繁殖策略形成石头剪刀布关系:blue 击败 yellow,yellow 击败 orange,orange 击败 blue。$n=3$ 的 replicator 动力学显示**5 年周期循环**,不收敛到任何静态均衡。

#### 5.7 Snowdrift(连续策略博弈)

(课件 slide 57-60)

$\Pi(X, Y) = B(X+Y) - C(X)$ — 集体收益但个人付成本,出现搭便车 (freeloaders)。这个博弈**无法用标准 replicator** 分析(因为投入是连续值),需要 Adaptive Dynamics 或带突变的群体模拟。

#### 5.8 补充理解:Cross-Learning 更新规则的直觉

假设你有两家咖啡店 A、B,概率 $P_A = 0.5, P_B = 0.5$。今天你去了 A,体验是 0.8(归一化效用)。
- 新 $P_A = 0.8 + 0.2 \times 0.5 = 0.9$
- 新 $P_B = 0.2 \times 0.5 = 0.1$

下次你**几乎肯定**会去 A。这就是"概率被拉向 1"的意思,拉力正比于体验有多好。

### 6. 易混淆点

#### 6.1 ESS vs. Nash vs. Strict Nash

- **Nash**:没人有动机偏离(可能多解,可能不稳定)
- **ESS**:Nash + 抗小规模突变入侵
- **Strict Nash**:偏离严格变差(自动满足 ESS)

**包含关系**:Strict Nash $\subset$ ESS $\subset$ Nash

**易混点**:不是所有 Nash 都是 ESS。例如本课介绍的"全等 payoff"博弈,所有策略都是 Nash 但都不是 ESS。

#### 6.2 个体学习 vs. 社会学习

- **个体学习**(Cross-Learning):"我从自己的 reward 学"
- **社会学习**(Imitation):"我观察并模仿邻居"

**关键事实**:它们在合适的极限下**服从同一个方程**(replicator)— 这是这节课最重要的、最反直觉的结论。

#### 6.3 Replicator 的"策略变化" — 容易误读

很多学生以为 replicator 描述"一个 agent 改变自己的策略"。**这是错的**。

正确理解:策略类型 (types) **是不可变的**(课件 slide 41 红字明示:"discrete set of (immutable) strategy types")。变化的是**类型的人口占比**。

如果你想描述"一个 agent 改变策略",那是 Cross-Learning 的视角(个体内部概率变化)。两者通过同构联系,但概念上要分清。

#### 6.4 Rest Point vs. Nash Equilibrium

不是所有 rest point 都是 Nash:边界 rest point $x_i = 0$ 只是因为"没人执行 $i$",不一定是 Nash。

Folk Theorem 说的是**稳定** rest point $\subseteq$ Nash —"稳定"这个词非常重要。

#### 6.5 Replicator 不能产生新策略

(课件 slide 68 强调)Replicator 只调整已有策略的占比,**不会创造新东西**。要研究"创新 / 突变",需要加突变项(replicator-mutator equation)或用 Adaptive Dynamics。

#### 6.6 Fitness vs. Payoff vs. Reward

虽然数学上经常互换使用,但概念上:
- **Payoff**(经典 GT):理性玩家追求最大化的目标
- **Fitness**(EGT):决定复制速度的量(策略层面,不是个体决策依据)
- **Reward**(RL):学习信号,驱动价值函数更新

这节课里它们在公式中可以互换,但在不同语境下解读不同。

### 8. 一句话总结

这节课用一条逻辑线把博弈论、生物学和强化学习串在一起:**当大量同质 agent 反复博弈时,无论是通过自然选择(进化)、模仿邻居(社会学习)、还是从自己的 reward 调整(Cross-Learning),群体的策略分布都遵循同一个数学结构 — 复制动力学方程**。这给了我们一套不依赖理性假设的工具,去分析多智能体系统会稳定在哪里 (ESS)、哪些均衡能抵抗扰动、以及什么时候 Nash 均衡反而是集体灾难 (Braess Paradox)。对你的项目来说,这套工具的真正威力是:**把一个看起来复杂的多 agent RL 训练问题,抽象成一个简单的 $2\times 2$ 对称博弈,然后通过 replicator 的相图直接预测训练会收敛到哪里、为什么会卡住**。
